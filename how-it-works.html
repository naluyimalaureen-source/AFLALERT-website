Technical Architecture

Screens call into services; services own all business logic and talk to Firebase, the bundled TFLite model, the device camera, and platform schedulers — keeping kernel and strip detection independently testable.

Frontend

Built with Flutter & Dart for a smooth, native-feeling cross-platform mobile experience.

Backend

Firebase powers authentication, cloud data storage (Firestore), and image storage.

AI Model

On-device TensorFlow Lite enables fast, offline aflatoxin risk detection.

State Management

Provider manages app state and reactive UI updates efficiently.
