Technical Architecture

Frontend

Built with Flutter & Dart for a smooth, native-feeling cross-platform mobile experience.

Backend

Firebase powers authentication, cloud data storage (Firestore), and image storage.

AI Model

On-device TensorFlow Lite (MobileNetV2) enables fast, offline aflatoxin risk detection.

State Management

GetX manages app state, navigation, and reactive UI updates efficiently.
